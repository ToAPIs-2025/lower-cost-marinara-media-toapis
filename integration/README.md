# Marinara Engine reuse recipe

## Verified proposal workflow (2026-10-20)

Use `python verify_marinara_flow.py` for a quote, then deliberately add `--live` to run the two-image / one-video contract check. See [request mapping and execution](proposed-media-contract.md) and [live evidence](../evidence/marinara-contract-2026-10-20.json). This dedicated script covers ordinary `gpt-image-2` URL-reference editing, which the older generic bridge does not enable. All three external tasks succeeded; full Marinara app acceptance is still pending.

Generate the image jobs with `run_case.py`, then import the three PNGs into Marinara's Gallery as original scene illustrations. Generate the first-frame video from `jobs/video.json` after uploading the first frame with `MediaEngine.upload_reference`; import the resulting MP4 as a scene asset.

The published image and Seedance 2 video examples were generated by the independent ToAPIs media client. Native Marinara Gallery import, Scene Video routing, Test Image/Test Video, and playback remain manual acceptance items. This guide does not tell users to point the built-in xAI service at ToAPIs: xAI uses `request_id` and `/videos/{id}`, while ToAPIs uses task `id`, `/videos/generations/{id}` and different reference fields. Marinara's outbound safety policy also rejects an arbitrary loopback video endpoint.

Native service support would require credential/settings registration, exact request/response mappings, task persistence, no automatic paid resubmission after ambiguous answers, output download, and cost receipt handling. The maintainer requested a focused Feature Issue with API documentation and will handle any Marinara-side implementation. The original community thread remains background context; native integration has not been accepted or implemented by this guide.

This is a ToAPIs-operated independent guide and is not affiliated with, endorsed by, or supported by Pasta-Devs. The examples are non-explicit environment artwork. No upstream source, project logo or character artwork is repackaged.
